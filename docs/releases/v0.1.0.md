# v0.1.0 发布说明

## 主要变化

- 旅行规划核心闭环上线：输入城市与景点，即可获得可行的每日行程（CA 秒级建议 + VNS 深度优化）。
- 支持与 LLM Agent 对话式调整行程，工具化查询 POI、驾车耗时，并可直接基于首页表单生成方案。
- 历史记录分享站：可保存/查看/分享规划结果；新增「关于」页用户反馈问卷。
- 异步任务体验：提交规划后前端轮询，不再长阻塞。

## 主要修改

- 求解引擎：CA / VNS 双引擎平级并行，6 种聚类选择；适应度（距离/等待/迟到/晚归）统一。
- Agent 编排：LangGraph 单 Agent 循环（LLM 决策 → 工具执行 → 回填）；工具注册表 TOOL_REGISTRY + 分组 TOOL_CATEGORIES（poi / plan / driving）。
- 异步化：suggest / plan / 方案调整改走 Celery + Redis，新增 plan_tasks 状态流转与任务清理。
- 文档站：ADR 重编号（001-009）并按 13 段模板统一；structure/ 各层文档模板化；design/、product/ 分层；index.rst 收敛 + 文件导航；handoff 交接文档结构与展示修复。
- 工程化：FastAPI + SSE、PostgreSQL / Redis、Docker Compose 一键部署、GitHub Actions（CI / Deploy / Docs / Release）。

## 已知限制 / 说明

- 文档站构建仍有来自 AutoAPI 的既有警告（与后端 docstring 相关），暂未处理。
- 多天场景下 CA 与 VNS 解质量趋同，fast / deep 收益可能不明显。
