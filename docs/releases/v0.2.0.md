# v0.2.0 发布说明

## 主要变化

- **用户账号系统**：注册 / 登录 / 退出 / 查看当前用户；登录后你的规划、聊天、任务记录个人专属，可跨刷新与设备恢复（httpOnly Cookie + 服务端会话）。
- **对话式行程规划**：与助手对话，输入城市/景点即可获得**可行每日行程**（CA 秒级建议 + VNS 深度优化）；可对话新增/删除景点、调整天数、修改行程。
- **会话记忆**：对话自动跨轮次续接，助手记住上文，不用重复需求。
- **异步任务面板**：提交规划/调整不再卡页面，后台计算，任务面板实时看进度、可取消。
- **管理操作台**：管理员（super_admin）可查看用户 / 任务 / 反馈（只读）。
- **历史分享**：保存/查看/分享规划结果；可提交反馈问卷。

## 主要修改

- 后端收敛为六边形架构（domain 端口/核心 + infrastructure 实现 + 组合根注入），换数据源/算法只动一处。
- 会话端口-适配器：会话读写收敛到 domain 端口 + Postgres 实现。
- CI/CD 拆分（CI 质量门禁 + CD 部署分离）、CI 全绿。
- 服务器部署修复（lavinmq 离线镜像 + Docker 源优化）。
- 架构依赖守护测试，防依赖方向回退。

## 已知限制 / 说明

- 对话会话实现目前在 `infra/auth/`（语义为"会话"非"认证"），后续可拆。
- 文档站 AutoAPI 既有警告未处理；多天场景 CA/VNS 解质量趋同（沿用）。
